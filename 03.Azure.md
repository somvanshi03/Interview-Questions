# Azure Services

### 🏗️ Azure Fundamentals: Regions, Resources, and Management

Before diving into specific services, it's essential to understand a few core concepts that form the foundation of how Azure works.

*   **Azure Regions & Availability Zones**: Azure is made up of data centers located all around the world, grouped into geographic areas called **regions** (e.g., "East US", "West Europe") . To ensure high availability and protect against data center failures, many regions contain **Availability Zones**. These are physically separate data centers within the same region. If one zone goes down, the others continue to operate .
*   **Azure Resource Manager (ARM)**: This is the central deployment and management service for Azure. You interact with ARM whenever you create, update, or delete resources. It allows you to manage your infrastructure as code using **ARM templates** or **Bicep** files, which are JSON/domain-specific language documents that define the resources and configurations for your solution .
*   **Management & Governance**: Azure provides a suite of tools to help you manage and govern your environment. **Azure Monitor** is the platform's comprehensive solution for collecting, analyzing, and acting on telemetry from your cloud and on-premises resources . This works with **Log Analytics**, a tool within Azure Monitor for querying log data . To enforce organizational standards, you can use **Azure Policy**, which creates rules that can audit or deny the creation of non-compliant resources . For securing secrets like API keys and connection strings, **Azure Key Vault** provides a secure, encrypted store .

### ☁️ Core Service Categories (A-Z)

The following table lists a wide range of Azure services, organized by category, with a brief description of what each service does.

| Service Category | Service Name | What it Does |
| :--- | :--- | :--- |
| **AI + Machine Learning** | **Azure AI Services** (formerly Cognitive Services) | A family of pre-built, ready-to-use APIs that enable you to add capabilities like vision, speech, language understanding, decision-making, and OpenAI models to your applications without needing machine learning expertise . |
| | **Azure Machine Learning** | A comprehensive cloud-based environment for building, training, deploying, and managing machine learning models at scale. It provides tools for all levels of expertise, from no-code design to advanced MLOps . |
| | **Azure AI Bot Service** | A managed service for building, testing, deploying, and managing intelligent bots that can interact naturally with users on various channels like websites, apps, Microsoft Teams, and more. |
| **Analytics** | **Azure Synapse Analytics** | A limitless analytics service that brings together enterprise data warehousing and Big Data analytics. It provides a unified experience to ingest, prepare, manage, and serve data for immediate business intelligence and machine learning needs . |
| | **Azure Data Lake Storage** | A highly scalable and secure data lake built on Azure Blob Storage, optimized for big data analytics workloads. It allows you to store trillions of files with high throughput . |
| | **Azure Data Factory** | A cloud-based ETL (extract, transform, load) and data integration service that allows you to create data-driven workflows for orchestrating and automating data movement and data transformation . |
| | **Azure HDInsight** | A fully managed, open-source analytics service for running popular open-source frameworks like Apache Spark, Apache Hadoop, Apache Kafka, and more. It's ideal for processing massive amounts of data. |
| | **Azure Databricks** | A fast, easy, and collaborative Apache Spark-based analytics platform optimized for Azure. It provides an interactive workspace for data scientists and engineers to collaborate on building and deploying data and AI solutions. |
| | **Azure Stream Analytics** | A real-time analytics service designed to process high volumes of fast streaming data from sources like IoT devices, sensors, and application logs. It can identify patterns and insights in milliseconds. |
| **Compute** | **Azure Virtual Machines (VMs)** | An IaaS offering that gives you full control over your computing environment. You create and manage VMs, including the operating system and all installed software. It's ideal for custom applications and lift-and-shift migrations . |
| | **Azure App Service** | A PaaS offering for hosting web applications, REST APIs, and mobile back ends. It supports multiple languages (like .NET, Java, Node.js, Python) and features auto-scaling, high availability, and easy CI/CD integration . |
| | **Azure Functions** | A serverless compute service that lets you run event-triggered code without having to explicitly provision or manage infrastructure. You pay only for the compute time you consume. It's perfect for microservices, data processing, and integrating systems . |
| | **Azure Kubernetes Service (AKS)** | A fully managed Kubernetes container orchestration service that simplifies deploying and managing containerized applications. It handles complex operational tasks like health monitoring and patching, allowing you to focus on your apps . |
| | **Azure Container Apps** | A serverless platform for running microservices and containerized applications. It provides the benefits of Kubernetes (like scaling and resilience) without the complexity of managing the underlying orchestrator. It integrates well with Dapr for building distributed applications . |
| | **Azure Container Instances (ACI)** | The fastest and simplest way to run a container in Azure without managing any virtual machines or higher-level services. It's great for simple tasks, development scenarios, and small-scale jobs . |
| | **Azure Batch** | A job scheduling platform that enables you to run large-scale parallel and high-performance computing (HPC) applications efficiently in the cloud. It provisions and manages a pool of compute nodes for you. |
| | **Azure Service Fabric** | A distributed systems platform that makes it easy to package, deploy, and manage scalable and reliable microservices and containers. It can run both stateless and stateful services and is used by many Microsoft services itself . |
| **Containers** | **Azure Container Registry (ACR)** | A managed, private Docker registry service based on the open-source Docker Registry. You can use it to store and manage container images and related artifacts across all types of Azure container deployments . |
| **Databases** | **Azure SQL Database** | A fully managed, intelligent, and scalable relational database service built for the cloud. It's a PaaS version of SQL Server, handling backups, patching, upgrades, and performance monitoring automatically . |
| | **Azure SQL Managed Instance** | A deployment option that provides near 100% compatibility with the latest SQL Server on-premises (Enterprise Edition) database engine. It's ideal for "lift-and-shift" migrations to Azure with minimal application changes. |
| | **Azure Cosmos DB** | A fully managed, globally distributed NoSQL database service that offers single-digit millisecond response times, automatic scaling, and comprehensive SLAs. It supports multiple data models (document, key-value, graph, etc.) and APIs, including a MongoDB-compatible API . |
| | **Azure Database for PostgreSQL/MySQL** | Fully managed, enterprise-ready community versions of these popular open-source databases. They provide built-in high availability, automatic patching, and scaling, freeing you from administrative overhead . |
| | **Azure Cache for Redis** | A secure, high-performance, and managed in-memory data store based on the open-source Redis. It's used as a cache, session store, and message broker to boost application throughput and performance . |
| **Developer Tools** | **Azure DevOps** | A set of development tools for the entire development lifecycle, including Azure Boards (work tracking), Azure Repos (private Git repos), Azure Pipelines (CI/CD), Azure Test Plans, and Azure Artifacts (package management). |
| **DevOps** | **Azure Pipelines** | A cloud-hosted CI/CD service within Azure DevOps that automatically builds, tests, and deploys your code to any platform or cloud. It supports multiple languages and application types. |
| **Hybrid + Multi-cloud** | **Azure Arc** | A service that extends Azure management and governance capabilities to any infrastructure, including on-premises, multi-cloud, and edge environments. You can manage servers, Kubernetes clusters, and data services outside of Azure as if they were native Azure resources . |
| **Identity** | **Microsoft Entra ID** (formerly Azure Active Directory) | Microsoft's cloud-based identity and access management service. It provides single sign-on (SSO), multi-factor authentication (MFA), and application access management for users to sign in and access resources . |
| **Integration** | **Azure Service Bus** | A fully managed enterprise message broker that supports point-to-point and publish-subscribe integrations. It's ideal for building decoupled, reliable, and scalable applications and for facilitating communication between microservices . |
| | **Azure Event Grid** | A highly scalable, serverless event routing service that uses a publish-subscribe model. It connects event sources (like Blob Storage or custom apps) to event handlers (like Functions or Webhooks), simplifying event-driven architectures. |
| | **Azure Event Hubs** | A big data streaming platform and event ingestion service capable of receiving and processing millions of events per second. It's a primary pipeline for ingesting telemetry and event data from websites, apps, and devices. |
| | **Azure Logic Apps** | A low-code/no-code integration service for automating workflows and orchestrating business processes. You can build integrations by connecting to hundreds of different SaaS and enterprise applications using a visual designer. |
| **Internet of Things (IoT)** | **Azure IoT Hub** | A managed service that acts as a central message hub for bi-directional communication between millions of IoT devices and your cloud solutions. It provides secure, reliable, and scalable device connectivity and management . |
| **Management + Governance** | **Azure Automation** | A service that provides process automation, configuration management, and update management for your Azure and non-Azure environments. It helps you automate frequent, time-consuming, and error-prone cloud management tasks . |
| | **Azure Advisor** | A free, personalized cloud consultant that analyzes your resource configuration and usage telemetry. It provides recommendations to help you optimize your Azure resources for reliability, security, performance, operational excellence, and cost . |
| | **Microsoft Sentinel** | A scalable, cloud-native security information and event management (SIEM) and security orchestration automated response (SOAR) solution. It provides intelligent security analytics and threat intelligence across the enterprise . |
| | **Microsoft Defender for Cloud** | A unified infrastructure security management system that strengthens the security posture of your data centers and provides advanced threat protection across your hybrid workloads in the cloud or on-premises . |
| **Media** | **Azure Media Services** | A platform for encoding, packaging, protecting, and delivering video and audio content at scale. It provides on-demand and live streaming capabilities for reaching a wide audience on any device. |
| **Migration** | **Azure Migrate** | A centralized hub to assess and migrate your on-premises servers, databases, and applications to Azure. It provides integrated tools and insights to simplify and accelerate your migration journey. |
| **Mixed Reality** | **Azure Digital Twins** | An IoT service that enables you to create a comprehensive digital model of a physical environment. A digital twin allows you to visualize, understand, and optimize real-world systems and processes. |
| **Mobile** | **Azure Notification Hubs** | A massively scalable push notification engine that allows you to send personalized push notifications to any mobile platform (iOS, Android, Windows, etc.) from any back end. |
| **Networking** | **Azure Virtual Network (VNet)** | The fundamental building block for your private network in Azure. A VNet allows your Azure resources to securely communicate with each other, the internet, and on-premises networks . |
| | **Azure Load Balancer** | A Layer 4 (TCP/UDP) load balancer that distributes incoming traffic across healthy VM instances. It ensures high availability and scalability for your applications . |
| | **Azure Application Gateway** | A Layer 7 (HTTP/HTTPS) web traffic load balancer with a Web Application Firewall (WAF) for protecting web apps from common exploits and vulnerabilities. It supports features like URL-based routing and SSL termination . |
| | **Azure Front Door** | A global, scalable entry point for your web applications. It provides capabilities like global load balancing, SSL offloading, and a WAF at the edge, closest to users . |
| | **Azure Traffic Manager** | A DNS-based traffic load balancer that allows you to distribute traffic optimally to services across global Azure regions. It uses various routing methods like priority, performance, and geographic to ensure high availability and responsiveness . |
| | **Azure DNS** | A hosting service for DNS domains that provides name resolution using the Microsoft Azure infrastructure. It's reliable, secure, and easy to manage your domain records. |
| | **Azure VPN Gateway** | A service that sends encrypted traffic between an Azure VNet and an on-premises location over the public internet. It's a key component for creating hybrid networks . |
| | **Azure ExpressRoute** | A service that lets you extend your on-premises networks into the Microsoft cloud over a private, dedicated connection facilitated by a connectivity provider. This provides more reliability, faster speeds, and lower latencies than typical internet-based connections . |
| | **Azure Private Link** | A service that enables you to access Azure PaaS services (like Azure Storage and SQL Database) and your own services over a private endpoint in your VNet, keeping all traffic on the Microsoft backbone network . |
| **Security** | **Azure confidential ledger** | A tamper-proof, unstructured data store hosted in trusted execution environments (TEEs). It provides cryptographic evidence of data integrity, making it ideal for storing sensitive information like financial records or legal contracts . |
| **Storage** | **Azure Blob Storage** | Massively scalable object storage for unstructured data, such as text, images, videos, and backups. It's the foundation for data lakes, backup and disaster recovery, and serving content directly to browsers . |
| | **Azure Disk Storage** | High-performance, durable block storage for Azure Virtual Machines. It offers various performance tiers (HDD, SSD, Premium SSD, Ultra Disk) to meet different workload demands . |
| | **Azure Files** | Fully managed file shares in the cloud that are accessible via the industry-standard Server Message Block (SMB) and Network File System (NFS) protocols. You can mount them concurrently from cloud or on-premises deployments . |
| | **Azure Queue Storage** | A simple, cost-effective service for storing large numbers of messages that can be accessed from anywhere via authenticated calls. It's used for creating a backlog of work and for decoupling application components . |
| | **Azure Table Storage** | A NoSQL key-value store for semi-structured data that offers a schemaless design. It's great for storing flexible datasets like user data, device info, or metadata . |
| | **Azure Elastic SAN** | A cloud-native storage area network (SAN) service that provides an end-to-end experience similar to an on-premises SAN. It offers built-in performance, redundancy, and scalability for large-scale workloads. |
| **Web** | **Azure Static Web Apps** | A service that automatically builds and deploys full-stack web apps to Azure from a code repository. It's designed for static front-end frameworks (like Angular, React, Vue) with optional serverless API back ends. |
| | **Azure SignalR Service** | A managed service that makes it easy to add real-time web functionality to applications. This allows for pushing content updates to connected clients, such as in live dashboards or chat applications. |
